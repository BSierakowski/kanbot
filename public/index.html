Kanbot can!

Kanbot keeps a shared kanban board for every Discord channel, so your group always knows what's todo, doing, and done. Just type /kanbot to add, move, and check off items.

Install Kanbot on your Discord Server

How it works

Every channel gets its own board. There's nothing to set up once Kanbot is installed, so just start typing.

  1. 1

    Install Kanbot

    Add Kanbot to your Discord server. It only adds the /kanbot command, and it doesn't read your messages.

  2. 2

    Run /kanbot in any channel

    Type /kanbot and pick a command. Discord shows you each option as you go, and everyone in the channel sees the same board.

  3. 3

    Open the web board

    /kanbot list ends with a link to a kanban board for the channel, where you can add cards and drag them between todo, doing, and done.

Commands

/kanbot list
Show the board, or pick a status to see just that column.
/kanbot add
Add an item. It goes in todo unless you pick another status.
/kanbot bulkadd
Add several items to todo at once, separated by commas.
/kanbot move
Move an item to another status, using its number from the list.
/kanbot remove
Remove an item, using its number from the list.
/kanbot help
Show a quick reminder of the commands.
